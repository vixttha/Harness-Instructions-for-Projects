# Harness Instructions for Projects (HIP)

**Instructions by design.**

*Engineer the instructions. Shape the outcome.*

HIP is an instruction engineering toolkit for AI projects: create, audit, refine, validate, version and maintain project instructions. ChatGPT Projects is the initial target; provider-neutral adapters are future work. HIP is not a governance management platform.

## Status

Development checkpoint v0.0.0.1 — Worker candidate, not accepted or released. First release target v0.0.1. Name provisional; commercial branding clearance pending.

See [checkpoint plan](docs/CHECKPOINTS.md), [handoff](docs/HANDOFF.md), [source pins](docs/sources.json), [migration procedure](docs/MIGRATION.md) and [license scope](HIP-NOTICE.md). No ecosystem product is required for standalone operation.

## Verification

Public GitHub-hosted Ubuntu only. Exact checkout, license, mechanical tests and read-only archive blob verification. A green run does not prove migration, live agent behavior or independent acceptance.
